## 2024-09-15 - Unhandled Exception (DoS) Risk in `crypto.timingSafeEqual`
**Vulnerability:** Comparing the `.length` of string variables before passing them to `Buffer.from()` and `crypto.timingSafeEqual()` can lead to a Denial of Service. Multi-byte characters can cause two strings to have the same string `.length` but different byte lengths when converted to `Buffer`. If `timingSafeEqual` is given Buffers of different lengths, it throws an unhandled exception, which could be exploited by an attacker submitting carefully crafted invalid multi-byte signatures to crash the server process.
**Learning:** `timingSafeEqual` strictly requires arguments of the same byte length. Node.js `Buffer.from()` resolves strings using UTF-8 encoding by default, where string length does not always equal byte length. The security check previously validated string length instead of buffer byte length.
**Prevention:** Always instantiate the `Buffer` objects first, and then compare the `.length` property of the `Buffer` instances before invoking `timingSafeEqual`.
