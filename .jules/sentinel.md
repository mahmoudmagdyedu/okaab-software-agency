## 2024-05-24 - [CRITICAL] Prevent DoS via `timingSafeEqual` Buffer Length Mismatch
**Vulnerability:** A Denial of Service (DoS) vulnerability existed when validating webhook signatures. The function `timingSafeEqual` was called on `Buffer` objects derived from strings, with the length check only comparing the string character lengths (`expected.length === supplied.length`). If a multi-byte character signature was supplied with the same character length but differing byte length, `timingSafeEqual` threw an unhandled exception causing an immediate server crash/DoS for that process.
**Learning:** Checking the character length of a string before instantiating buffers and passing them to `timingSafeEqual` is insufficient. `timingSafeEqual` strictly requires input buffers to have identical byte lengths.
**Prevention:** Always compare the `.length` or `.byteLength` property of the `Buffer` objects themselves immediately before calling `timingSafeEqual`, returning `false` if they do not match.
