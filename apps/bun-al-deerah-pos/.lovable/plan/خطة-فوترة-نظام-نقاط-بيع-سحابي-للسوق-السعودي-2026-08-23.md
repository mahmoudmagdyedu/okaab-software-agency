# خطة «فوترة» — نظام نقاط بيع سحابي للسوق السعودي

## ملاحظة تنفيذية واحدة

الملف هنا تطبيق ويب حقيقي (React + Tailwind) لا ملف Figma — لذلك كل «فريم» سيُبنى كصفحة/مسار فعلي بنفس التسمية `area/screen — state`، والتوكنز كـ CSS Variables بنمطين (Light للإدارة / Dark للكاشير) في نظام تصميم واحد. هذا يعادل Variables بنمطين تمامًا.

## المرحلة الأولى (هذه الدفعة — ثم أتوقف لموافقتك)

### 1) ملخص Brief — 10 أسطر (يظهر في الصفحة الرئيسية `/`)

```text
01 النطاق: ~35 شاشة — POS داكن (7 حالات) + إدارة فاتحة + KDS + منيو QR + موبايل 375px.
02 البيانات: مقهى «بُنّ الديرة» — فرعان (النرجس/الروضة)، 80 صنفًا، 500 فاتورة، 4 موظفين.
03 المال: أسعار ريال بكسور هللة، ضريبة 15%، كل الأرقام JetBrains Mono باتجاه LTR.
04 اللغة: عربي RTL كامل بلا حرف لاتيني واحد؛ الجزر LTR الوحيدة = الأرقام والباركود.
05 النمطان: كاشير داكن (#0E1116) بأهداف لمس ≥44px / إدارة فاتحة كثيفة بإحساس Stripe.
06 اللون: عائلة عنبر واحدة (#B45309 فاتح / #FBBF24 داكن) + دلالية رباعية فقط — بلا لون سادس.
07 القرار المفتوح 1: «فريمات Figma» → مسارات ويب حية بنفس الأسماء (حُلّ: صفحة فهرس تجمعها).
08 القرار المفتوح 2: الأدوار الخمسة → Annotation ثابت في App Shell يوضح ما يُخفى لكل دور.
09 القرار المفتوح 3: حالات البيانات الأربع (محمّل/فارغ/تحميل/خطأ) إلزامية لكل سطح — مجدولة لكل شاشة.
10 الصياغة القانونية الوحيدة: «متوافق تقنيًا مع متطلبات المرحلة الثانية — بيئة تجريبية».
```

### 2) صفحة Foundations — `/foundations`

- تعريف كل التوكنز في `src/styles.css` بنمطين: `:root` = Light الإدارة، `.dark` = Dark الكاشير:
  bg/base · bg/subtle · bg/overlay · border/subtle · text/primary · text/secondary · text/muted · accent/50–700 · الدلالية الأربع بنسختيها.
- الخطوط عبر `<link>` في `__root.tsx`: IBM Plex Sans Arabic للواجهة + JetBrains Mono للأرقام (كلاس `.font-mono-num` مع `direction: ltr`).
- مقياس الخط كاملًا: display 32/40 … price-total 28/36 Mono.
- الصفحة نفسها معرض حي: عينات ألوان النمطين جنبًا إلى جنب، مقياس الخط، مضاعفات 8، الحواف 6/10/16، وأمثلة التباين.

### 3) الشاشة البطل — `pos/cashier — default` على `/pos`

- 1440×900 داكنة بملء الشاشة، بلا قائمة جانبية، خلفية `#0E1116`.
- شريط علوي 56px: «الرياض — حي النرجس» + «سالم الدوسري» + شارة «الشفت الصباحي» يمينًا؛ حبة مزامنة خضراء «متصل» + ساعة `14:32` Mono LTR + زر «إنهاء الشفت» يسارًا.
- منطقة الأصناف (62% يمينًا): بحث مثبّت «ابحث بالاسم أو امسح الباركود…»، شريط فئات 44px (الكل، مشروبات ساخنة، مثلجة، شاي وكرك، حلويات، سندويتشات)، شبكة 5 أعمدة من قائمة أصناف حقيقية بأسعار بكسور، نقطة لون فئة، وصنف نافد معطّل بشارة «نفد».
- السلة (420px يسارًا): أزرار العميل/تعليق/استرجاع، أسطر بستيببر 44px وأيقونة خصم سطر، تذييل ثابت، وزر دفع 56px.
- بيانات السلة حرفيًا: لاتيه ×2 (33.00) + كورتادو (15.00) + كيكة تمر (13.50) + شاي كرك ×3 (25.50) → فرعي 87.00 / خصم 0.00 / ضريبة 13.05 / **الإجمالي 100.05** بـ price-total، وزر «الدفع — 100.05 ر.س».
- تفاعل حقيقي خفيف: إضافة صنف للسلة والستيببر يعيدان الحساب (الضريبة 15% تُحسب فعليًا).

### ملفات المرحلة

- `src/styles.css` — التوكنز بنمطيها + مقياس الخط.
- `src/routes/__root.tsx` — الخطوط + عنوان المشروع.
- `src/routes/index.tsx` — صفحة Brief بفهرس الشاشات.
- `src/routes/foundations.tsx` — معرض الأسس.
- `src/routes/pos.tsx` — شاشة الكاشير (سطح `.dark` مستقل).

## المراحل التالية (بعد موافقتك — لا أبدأها الآن)

المكونات بكل حالاتها ← حالات الكاشير الست الباقية (offline/payment/held/pin/loading/empty) ← المصادقة والشفتات ← الفواتير ومراقب الفوترة والربط التجريبي ← الأصناف والمخزون ← التقارير ← KDS والمنيو ← الإعدادات ← موبايل 375px.
